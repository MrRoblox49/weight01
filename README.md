# ตาชั่งสั่น (Vibe Scale)

เว็บแอปประมาณน้ำหนักของเล็กๆ ด้วยมอเตอร์สั่นและ accelerometer ในมือถือ
**ใช้ได้เฉพาะ Chrome บน Android** (iPhone ไม่รองรับ Vibration API) และแม่นยำต่ำ เหมาะกับโปรเจกต์ทดลอง ไม่ใช่ตาชั่งจริง

## หลักการ

วางของบนมือถือที่กำลังสั่น ของยิ่งหนัก แอมพลิจูดการสั่นที่เซนเซอร์อ่านได้ยิ่งลด
แอปจึงให้คุณวัดของที่รู้น้ำหนัก (คาลิเบรต) แล้วสร้างสมการ `1/แอมพลิจูด = a + b × น้ำหนัก`
จากนั้นย้อนสมการเพื่อประมาณน้ำหนักของใหม่

## ขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ให้ `index.html` อยู่ที่ root)
2. ไปที่ Settings → Pages
3. Source: Deploy from a branch, Branch: `main` / `(root)` แล้วกด Save
4. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` (เป็น HTTPS อยู่แล้ว)
5. เปิดลิงก์บนมือถือ Android ด้วย Chrome แล้วเลือก "เพิ่มลงหน้าจอหลัก" ถ้าอยากใช้เหมือนแอป

## วิธีใช้

1. **ตรวจเครื่อง**: กด "เริ่มตรวจเซนเซอร์" แล้ว "ทดสอบสั่น" ถ้าแอมพลิจูดชัดเจน ไปต่อได้
2. **คาลิเบรต**: วางมือถือหงายจอบนโต๊ะแข็งเรียบ ถอดเคส วางของที่รู้น้ำหนักกึ่งกลางหลังเครื่อง
   วัดอย่างน้อย 3 น้ำหนัก (แนะนำ 0, 20, 50, 100 g) เหรียญ 1 เยนหนัก 1 g ใช้กองเป็นตุ้มได้
3. **ชั่ง**: วางของที่ตำแหน่งเดิม กด "ชั่ง" แอปจะแสดงค่าประมาณพร้อมช่วงความคลาดเคลื่อน

## เคล็ดลับให้แม่นขึ้น

- ใช้โต๊ะแข็ง เรียบ นิ่ง ที่เดิมทุกครั้ง และถอดเคสเหมือนตอนคาลิเบรต
- วางของตำแหน่งเดียวกันเสมอ ควรกองเป็นก้อนเดียว
- อย่าแตะเครื่องหรือโต๊ะระหว่างวัด
- คาลิเบรตใหม่เมื่อเปลี่ยนเครื่อง เคส หรือโต๊ะ
- ข้อมูลคาลิเบรตเก็บในเบราว์เซอร์ของเครื่อง (localStorage) ล้างข้อมูลเว็บแล้วจะหาย

## ข้อจำกัดที่ควรรู้

- ค่าที่ได้เป็นการประมาณ ความคลาดเคลื่อนขึ้นกับรุ่นมือถือและโต๊ะ ดูค่า RMSE ในหน้าคาลิเบรตเป็นตัวชี้วัดของเครื่องคุณเอง
- เซนเซอร์ในเบราว์เซอร์อ่านได้ราว 60 Hz ซึ่งต่ำกว่าความถี่มอเตอร์สั่น แอปจึงใช้พลังงานรวมของสัญญาณ (RMS) แทนการวัดความถี่ตรงๆ
- ถ้าแอปบอกว่า "เซนเซอร์แทบไม่เห็นการสั่น" ให้ตรวจว่าเครื่องไม่ได้ปิดการสั่นหรืออยู่ในโหมดประหยัดแบตเตอรี่
